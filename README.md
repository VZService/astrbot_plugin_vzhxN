# VZ核心（公开版）

此版本为*公开版*，不含 v 系列（绑定/签到/积分）指令。

完整版请访问：https://github.com/VZService/astrbot_plugin_vzhx

---

一个功能丰富的 AstrBot 核心，集成了多种娱乐和实用功能，并支持通过 WebUI 进行灵活配置。

---

## ⚠️ 注意事项
- 营销号模板中的 `{}` 是必须的占位符，程序会自动替换为用户输入的主题或随机主题。

---

## ✨ 功能概览

| 功能 | 命令 | 描述 |
|------|------|------|
| **关于** | `about` / `关于` | 输出插件信息、作者、仓库与版本 |
| **今日人品** | `jrrp` | 随机生成今日人品值，附带等级评语和额外提示 |
| **投骰子** | `投骰子` | 掷出指定面数的骰子（默认6面，可配置） |
| **冷知识** | `冷知识` | 随机返回一条冷知识（可自定义库） |
| **猜数字游戏** | `猜数字` | 开始猜数字游戏（范围可配置） |
| **废话文学** | `废话` | 随机获取一句废话文学（可自定义库） |
| **营销号文案** | `营销号 [主题]` | 生成营销号风格的文案，主题可选 |
| **刷屏** | `刷屏 "文本" [次数] [毫秒]` | 管理员指令，在当前群重复发送文本（次数0为无限，间隔默认999ms） |

所有功能均可在 AstrBot WebUI 的插件配置页面中进行开关和自定义设置。

---

## ⚙️ 配置说明

### 通用开关
- **启用 jrrp(今日人品) 功能**：开启/关闭 `jrrp` 命令。
- **启用 投骰子 功能**：开启/关闭 `投骰子` 命令。
- **启用 冷知识 功能**：开启/关闭 `冷知识` 命令。
- **启用 猜数字 功能**：开启/关闭 `猜数字` 命令。
- **启用 废话 功能**：开启/关闭 `废话` 命令。
- **启用 营销号 功能**：开启/关闭 `营销号` 命令。
- **启用 刷屏 功能**：开启/关闭 `刷屏` 命令。

### 内容自定义
- **jrrp 运势等级阈值**：设置"大吉"、"吉"等等级所需的最低人品值。
- **jrrp 运势评语库**：按等级自定义多条评语，每天随机选择。
- **jrrp 额外提示语**：附加在运势结果后的随机提示列表。
- **骰子面数**：设置 `投骰子` 的最大面数（2~100）。
- **冷知识库**：增删冷知识条目。
- **猜数字范围**：设置游戏目标数字的最小值和最大值。
- **废话文学库**：自定义废话语录。
- **营销号模板**：
  - 标题模板（使用 `{}` 作为主题占位符）
  - 正文模板（使用 `{}` 作为主题占位符）
  - 结尾附加语

## 📝 命令列表

| 命令 | 说明 |
|------|------|
| `about` / `关于` | 输出插件信息 |
| `jrrp` | 获取今日人品运势 |
| `投骰子` | 掷骰子（根据配置的面数） |
| `冷知识` | 随机一条冷知识 |
| `猜数字` | 开始猜数字游戏，随后使用 `猜数字 [数字]` 进行猜测 |
| `废话` | 随机一句废话文学 |
| `营销号 [主题]` | 生成营销号文案，不指定主题则随机选取常见主题 |
| `刷屏 "文本" [次数] [毫秒]` | 管理员指令，在当前群重复发送文本（次数0为无限，间隔默认999ms）。例：`刷屏 "你好" 10 500` |
